# Power BI | Портфоліо аналітичних проєктів

Колекція інтерактивних дашбордів, створених у Microsoft Power BI для аналізу бізнес-показників, фінансових результатів та ефективності діяльності.

## Мої проєкти

### 1. Фінансово-економічний аналіз продажів

**Аналіз:** виторг, прибуток, рентабельність, динаміка продажів, сегменти та продукти.

**Інструменти:** Power BI, DAX, Power Query.

[Переглянути фінансовий дашборд](https://github.com/Litcheveckiy3477/power-bi-financial-dashboard)

## Технології

- Power BI
- DAX
- Power Query
- Фінансова та бізнес-аналітика

*Портфоліо поповнюватиметься новими проєктами.*
### 2. Аналіз ефективності продажів, команд та продуктів

**Аналіз:** воронка продажів, конверсія угод, результативність менеджерів, ефективність продуктового портфеля, концентрація доходу та потенціал зростання.

**Інструменти:** Power BI, DAX, Power Query, Data Modeling.

**Методи:** KPI-аналіз, аналіз Парето, теплова карта, матриця ефективності продуктів, дерево декомпозиції.

[Переглянути дашборд ефективності продажів](https://github.com/Litcheveckiy3477/power-bi-sales-performance-dashboard)

### 3. Комплексний аналіз E-Commerce | Olist

**Аналіз:** динаміка продажів, платіжна поведінка, логістика, ефективність продавців, задоволеність покупців, RFM-сегментація та когортний аналіз.

**Інструменти:** Power BI, DAX, Power Query, Data Modeling, Time Intelligence, статистичний аналіз.

[Переглянути E-Commerce дашборд](https://github.com/Litcheveckiy3477/olist-ecommerce-power-bi)
