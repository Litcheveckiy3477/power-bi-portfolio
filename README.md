# Power BI | Портфоліо аналітичних проєктів

Колекція інтерактивних дашбордів, створених у Microsoft Power BI для аналізу бізнес-показників, фінансових результатів та ефективності діяльності.

## Мої проєкти

### 1. Фінансово-економічний аналіз продажів

**Аналіз:** виторг, прибуток, рентабельність, динаміка продажів, сегменти та продукти.

**Інструменти:** Power BI, DAX, Power Query.

[Переглянути фінансовий дашборд](https://github.com/Litcheveckiy3477/power-bi-financial-dashboard)

## Технології

- Power BI
- DAX
- Power Query
- Фінансова та бізнес-аналітика

*Портфоліо поповнюватиметься новими проєктами.*
